# Kora Coffee Co.

A responsive React + TypeScript + Tailwind CSS cafe website created for a university web development assignment.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

## Stack

- React
- TypeScript
- Vite
- Tailwind CSS

The project uses Cormorant Garamond and Inter. No Claude fonts are used.
